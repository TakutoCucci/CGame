# 音声ファイル配置ガイド

このフォルダに以下の音声ファイルを配置してください：

## 必要な音声ファイル

1. **drag.mp3** - カードをドラッグ開始時の音
2. **drop.mp3** - カードをドロップ時の音
3. **correct.mp3** - 正解時の音
4. **incorrect.mp3** - 不正解時の音
5. **timeUp.mp3** - 時間切れ時の音
6. **tick.mp3** - 残り 10 秒以下のカウントダウン音
7. **bgm.mp3** - ゲーム中の BGM
8. **start.mp3** - ゲーム開始時の音
9. **button.mp3** - ボタンクリック時の音

## 音声ファイルの取得方法

### 無料音声素材サイト

- [Freesound](https://freesound.org/)
- [Zapsplat](https://www.zapsplat.com/)
- [BBC Sound Effects](https://sound-effects.bbcrewind.co.uk/)

### 音声ファイルの形式

- 形式: MP3
- サンプリングレート: 44.1kHz 推奨
- ビットレート: 128kbps 以上推奨
- ファイルサイズ: 各ファイル 1MB 以下推奨

## 音声ファイルの命名規則

ファイル名は必ず上記の名前で保存してください。大文字小文字も正確に合わせてください。

## 注意事項

- 音声ファイルは著作権に注意して使用してください
- 商用利用の場合は適切なライセンスを確認してください
- ファイルサイズが大きすぎると読み込みに時間がかかる場合があります
